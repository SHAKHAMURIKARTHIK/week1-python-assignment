# Week 1 Python Basics: Personal Introduction Program

## About this project

This is my first small Python project. I made a program that asks the user a few simple questions and then uses the answers to create a friendly introduction.

The program asks for:
- Name
- Age
- City
- Favourite hobby

## What I practised

While making this project, I practised:
- Using `input()` to ask questions.
- Saving answers in variables.
- Printing messages with `print()`.
- Joining text and variable values with f-strings.
- Using `.strip()` to remove extra spaces at the beginning or end of an answer.

## How to run it

1. Make sure Python 3 is installed on your computer.
2. Download this repository or open the project folder in your code editor.
3. Open a terminal in the folder.
4. Run this command:

   ```bash
   python personal_intro.py
   ```

   If your computer uses `python3`, run `python3 personal_intro.py` instead.
5. Answer the questions shown in the terminal.

No extra Python packages are needed.

## Example

```text
Welcome to my Personal Introduction Program!

What is your name? Alex
How old are you? 21
Which city do you live in? Guntur
What do you enjoy doing in your free time? Coding

Here is your introduction:
Hi Alex, nice to meet you!
You are 21 years old, live in Guntur, and enjoy Coding.
Thanks for telling me a little about yourself. Have a great day!
```
